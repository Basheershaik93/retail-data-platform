# Retail Data Engineering Platform

An end-to-end retail data platform built with Python, Apache Airflow, Snowflake, dbt, and Power BI.

## Architecture

- Python: ingest and validate retail order data.
- Apache Airflow: orchestrate pipeline workflows.
- Snowflake: store raw, staging, and analytics-ready data.
- dbt: transform data and test data quality.
- Power BI: visualize retail performance and business KPIs.

## Project Goals

- Build a reliable, maintainable data pipeline.
- Implement data quality checks and transformation tests.
- Organize warehouse layers for analytics.
- Create interactive business intelligence dashboards.
- Track changes using Git and GitHub.
